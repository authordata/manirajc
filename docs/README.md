# Emotional Support Platform (MVP Foundation)

This repository now contains a production-oriented starter for your startup idea:

- **backend/**: FastAPI service with role-aware onboarding, support matching, chat, AI bot endpoint, feedback/reporting.
- **frontend/**: Lightweight web client demonstrating onboarding, dashboard, and chat behavior.
- **android/**: Native Android starter (Kotlin) with API client models and starter activities.
- **docs/**: Product + technical docs.

## MVP Roles

1. **Support Seeker**
2. **Support Giver**
3. **AI Support (customizable chatbot endpoint)**

## Security and ethics notes

- This app is **not a replacement for clinical care**.
- Add emergency escalation UX + local helpline links before launch.
- Introduce moderation and abuse prevention before opening volunteer sign-ups.
